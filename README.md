# Косплей: девушка-демон с капюшоном и крыльями

Полный гайд: выкройки, материалы со ссылками, грим, порядок сборки.
Ориентировочный бюджет: **3 700–7 800 ₽** (меньше, если часть вещей уже есть дома).

---

## 1. Мерки (снять перед началом)

- Обхват головы (для капюшона)
- Обхват груди (ОГ) и талии (ОТ) — для платья
- Длина от плеча до середины бедра — длина платья
- Обхват плеча и предплечья — для обмоток
- Ростовка стопы — для обмоток ступней

---

## 2. Выкройка капюшона с ушками

**Деталь капюшона** — кроить 2 шт зеркально, сшить по верхнему (затылочному) шву:

```
        32 см (1/2 обхвата головы + 4 см)
   <-------------------------------->
    _______________
   /               \
  |                 \___
  |                     \        ^
  |   ДЕТАЛЬ             |       |
  |   КАПЮШОНА           |       |  38–40 см
  |                     /        |  (от плеча до макушки
  |                ____/         |   + напуск на лоб)
   \              /              |
    \____________/               v
   ^
   сгиб (затылок) — линия сгиба ткани
```

- Припуски на швы: 1 см
- Нижний край — напуск на плечи

**Ушки** (как у кошки/демона):

```
      /\
     /  \      высота 16–18 см
    /    \
   /______\
  основание 12–14 см
```

- 2 шт из основной ткани + 2 шт из светлой (внутренняя сторона)
- Внутрь — тонкий поролон или картон для формы
- В основание — флористическая проволока, чтобы ушки стояли
- Пришивать к капюшону ДО сборки верхнего шва — шов спрячется внутри

**Ленивый вариант:** купить дешёвое чёрное/тёмно-синее худи и пришить ушки.

---

## 3. Выкройка крыльев летучей мыши

Кроить 2 шт зеркально. Размах одного крыла 55–60 см, высота ~45 см (небольшие крылья, как на арте).

```
 точка крепления
 к спине ●
        |\
        | \___ «палец» 1 (самый длинный, вверх)
        |     \__ ⌒
        |          \ «палец» 2
        |        ⌒  \
        |      ⌒     \ «палец» 3
        |    ⌒        \
        |  ⌒           \ «палец» 4 (вниз)
        |________________
         перепонка между пальцами —
         вогнутые дуги (провисание 8–9 см)
```

**Порядок сборки:**

1. Каркас: проволока 2–3 мм — 4 «пальца» на крыло, концы соединить у основания, замотать изолентой
2. Перепонка: чёрный креп-сатин / сетка / EVA-foam 2 мм / **ткань от сломанного зонта (бесплатно)**
3. Прожилки: прорисовать горячим ножом или выдавить разогретым носиком паяльника по линейке
4. Покраска: акрил — чёрная основа, сухой кистью градиент к тёмно-синему, красноватый оттенок по краям
5. Крепление: две лямки как у рюкзака (стропа + пряжки) под платьем, либо пластина-основа

---

## 4. Схема платья-сорочки

Простая трапеция, без рукавов. Перед 1 шт + спинка 1 шт.

```
      V-вырез со шнуровкой
   \  \          /  /
    \  \________/  /     ширина верха = ОГ/2 + 4 см
     \            \
      \            \     длина 75–85 см
       \            \    (от плеча до середины бедра)
       /  разрез     \
      /  8–12 см      \  ширина низа = +8–10 см от верха
     /________________\
```

- **Второй слой подола** — на 6–8 см короче основного, пришить по линии талии (двухслойный край, как на арте)
- Края разрезов из синтетики — опалить зажигалкой, чтобы не сыпались
- Спереди — шнуровка атласной лентой
- Поверх груди — ремешки-стропы крестом (чёрная стропа 2–2,5 см)

**Вариант без шитья:** готовое чёрное платье-сорочка с маркетплейса + доработка (шнуровка, ремешки, разрезы).

---

## 5. Обмотки и ремешки

| Зона | Что делать |
|---|---|
| Левая рука | Чёрный эластичный бинт спиралью от кисти до локтя, поверх 2–3 узких ремешка с пряжками |
| Правая рука | Белый бинт, заранее прокрасить чёрными полосами (краска по ткани), намотать так же |
| Ноги | Чёрные легинсы + эластичная лента 2–3 см крест-накрест, мелкие пряжки; сердечки-пряжки вырезать из EVA-foam и покрасить серебряной акриловой краской |
| Ступни | Бинт «сандалиями», пальцы и пятка открыты; для конвента под низ — телесные балетки или силиконовые накладки на стопу |

## 8. Грим — пошагово

1. **Тон:** светлый тональник на лицо, шею, уши, декольте и кисти рук; сверху рассыпчатая пудра
2. **Скульптурирование:** холодный серо-коричневый оттенок — лёгкие тени под скулами и на ключицах
3. **Линзы:** надеть ДО макияжа глаз. Красные или красно-оранжевые. Заранее привыкнуть (2–3 примерки дома), соблюдать гигиену (капли, контейнер)
4. **Глаза:** бордово-малиновая тень в складку века и под нижнее веко, растушёвка к виску; под нижним веком — приглушённый тёмно-красный (эффект «уставшего» взгляда)
5. **Подводка:** тонкая стрелка с острым кончиком; слизистая нижнего века — чёрным карандашом; нижние ресницы можно подрисовать лайнером
6. **Ресницы:** накладные, с удлинением к внешнему углу
7. **Брови:** прокрасить тёмно-розовыми/малиновыми тенями под парик
8. **Губы:** блеск как база, по центру — тёмно-вишнёвый тинт, растушёванный пальцем
9. **Финал:** спрей-фиксатор. С собой на конвент — пудра, тинт и зеркальце

---

## 9. Порядок сборки образа в день выхода

1. Линзы → тон → глаза → брови → губы → фиксатор
2. Парик (сетка под низ) → капюшон, ушки поправить поверх
3. Легинсы + ремешки на ногах → обмотки ступней → балетки
4. Платье → обмотки рук → крылья на лямках
5. Поднос со свечой в руку — образ готов
